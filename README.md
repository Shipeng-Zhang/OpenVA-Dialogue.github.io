# OpenVA Dialogue Demo

Research demo page for realtime dialogue generation.

The page is designed as a static GitHub Pages site. Video samples are stored beside `index.html` and are loaded with relative paths, so the repository can be served directly without a backend.

The Benchmark section includes an `Ours vs Vidu` layout. A Vidu export can be previewed locally with the upload control; to publish a permanent Vidu baseline, add the exported clip to the repository and replace the placeholder in `index.html` with its relative path.
